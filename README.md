# StreamVibe: сайт фильмов и сериалов

Одностраничный сайт с каталогом, фильтрами, регистрацией и выбором подписки.
Открывается без сборщика и без сервера: достаточно статического хостинга или любого локального сервера.

## Структура

```
streamvibe/
├── index.html          разметка: шапка, ленты, каталог, жанры, тарифы, окна
├── css/
│   ├── base.css        токены, типографика, кнопки (с состояниями), шапка, hero
│   ├── sections.css    ленты, карточки, фильтры, жанры, тарифы, отзывы, FAQ, футер
│   └── modals.css      формы, окна, личный кабинет, уведомления, карточка фильма
├── js/
│   ├── data.js         каталог фильмов и сериалов + настройки (CONFIG)
│   ├── app.js          модальные окна (Esc, фокус-ловушка), уведомления, шапка, анимации
│   ├── catalog.js      фильтры, сортировка, ленты, «Мой список», карточка фильма, TMDB
│   ├── auth.js         регистрация, вход, проверка полей, личный кабинет
│   └── plans.js        тарифы, месяц/год, оформление, смена и отмена подписки
└── images/posters/     сюда кладём постеры: <id>.jpg
```

Порядок подключения скриптов важен и уже задан в `index.html`: `data.js` → `app.js` → `catalog.js` → `auth.js` → `plans.js`.

## Запуск

Вариант 1, самый простой: открыть `index.html` в браузере.

Вариант 2, с локальным сервером (рекомендуется, так работает всё, включая запросы к TMDB):

```bash
cd streamvibe
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Постеры (реальные фотографии)

## Реальные постеры, описания и рейтинги через TMDB (бесплатно)

1. Зарегистрируйтесь на <https://www.themoviedb.org> и получите API-ключ (раздел Settings → API).
2. Вставьте ключ в `js/data.js`:
   ```js
   SV.CONFIG = {
     tmdbApiKey: "ВАШ_КЛЮЧ",
     ...
   };
   ```
3. Обновите страницу. Сайт сам найдёт каждый тайтл, подставит постер, описание на русском и рейтинг TMDB. Ответы кешируются в браузере на 7 дней.

Порядок приоритета постера: сначала файл из `images/posters/`, потом TMDB.

## Рейтинги

В `data.js` указаны рейтинги IMDb **ориентировочно**, на момент подготовки сайта. Они не сверены с живой базой. Перед запуском проверьте значения на imdb.com или включите TMDB, тогда рейтинг будет подтягиваться автоматически (с пометкой «TMDB»).

## Добавить свой фильм

В массив `SV.titles` в `js/data.js` добавьте объект:

```js
{
  id: "my-film",                       // уникальный, латиницей, совпадает с именем постера
  title: "Название на русском",
  original: "Original Title",          // используется для поиска в TMDB
  year: 2024,
  type: "movie",                       // movie | series | doc | anime
  genres: ["Драма", "Триллер"],        // жанры на русском
  rating: 8.0,
  duration: 120,                       // минуты (для фильмов)
  // seasons: 2,                       // для сериалов
  country: "США",
  director: "Имя Фамилия",
  g: ["#1e3a8a", "#0f766e"],           // цвета градиента-заглушки
  description: "Описание в одно-два предложения."
}
```

## Фильтры каталога

- тип: все, фильмы, сериалы, документальные, аниме;
- жанры: можно выбрать несколько, подойдёт любой из них;
- поиск по названию, оригинальному названию и режиссёру;
- год выпуска «от» и «до»;
- страна;
- минимальный рейтинг (ползунок);
- сортировка: по рейтингу, новые, старые, по названию.

## Регистрация, вход и подписка: важно

Это **демо на фронтенде**. Пользователи, пароли (в виде SHA-256 хэша с солью) и выбранный тариф хранятся в `localStorage` браузера. Это работает только на одном устройстве и в одном браузере.

Для реального сайта нужен бэкенд:

- хранение пользователей и сессий на сервере (не в браузере);
- HTTPS и защита от перебора паролей (rate limit, капча);
- подтверждение почты;
- платёжный провайдер (ЮKassa, CloudPayments, Stripe). Данные карт нельзя принимать и хранить на собственном фронтенде, это требование PCI DSS. Окно оформления в `plans.js` ничего не списывает и карту не запрашивает.

Для интеграции с бэкендом заменяйте функции `register`, `login`, `getUser`, `updateUser` в `js/auth.js`. Остальной код менять не нужно.

## Кнопка «Смотреть»

Проверяет состояние пользователя:

- гость → окно регистрации;
- без тарифа → переход к тарифам;
- есть тариф → уведомление о демо-воспроизведении. Реального плеера нет: для него нужна лицензия на контент и CDN.

## Браузеры

Современные Chrome, Firefox, Safari и Edge. Для `backdrop-filter` и `:where()` нужны версии 2021 года и новее.
